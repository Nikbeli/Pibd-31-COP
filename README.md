# Pibd-31-COP
Изучение курса по разработке в парадигме Компонентно-ориентированного программирования. Данный стиль разработки программного обеспечения (ПО) направлен на создание программной системы (ПС) из слабосвязанных и повторно используемых компонентов. Данный подход под капотом вращается вокруг упаковки кода в компоненты.
